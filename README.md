# PICO Unity SDK

This repository contains Unity packages for developing applications for PICO XR devices.

## Packages

| Package | Description |
| --- | --- |
| `XR` | PICO XR package for display, input, platform, enterprise, Sense Pack, SecureMR, Spatial Audio, Camera Pack, Interaction Pack, and related editor tooling. |
| `SpatialAdapter` | PICO Spatial Adapter runtime package for Shared Space applications, including runtime support, editor setup, exporting, and local simulation helpers. |

## Package Documentation

- `XR/README.md` contains the PICO XR package notes.
- `SpatialAdapter/README.md` contains SpatialAdapter runtime release notes.
- `XR/package.json` and `SpatialAdapter/package.json` define each Unity package manifest.
